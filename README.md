# NCKU CSIE special-admission practice

Personal private practice materials for the NCKU CSIE special-admission practical exam.

- `demo/`: Docker practice environment for ROS 2, bitwise/PIO reading, pthread and transfer-engine concepts.
- `notes/`: local setup notes and exam-rule notes.
- `docs/`: official pre-exam practice PDF.

The repository intentionally excludes generated binaries, build output, credentials, and local environment state.
