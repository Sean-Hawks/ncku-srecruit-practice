# 位元運算：指定哪些 bits 要留下或改掉

**mask 的 1 表示選到該位置。先確定位置，再決定要取出、設一、清零或替換。** bit 編號從右邊的 0 開始。

```text
0xA5 = 1010 0101
位置    7654 3210
```

## 常用公式

以下假設 x 是 uint32_t、0 <= n < 32，欄位完全落在 32 bits 內。

| 要做什麼 | 寫法 | 例子 |
|---|---|---|
| 留低四位 | `x & 0xFu` | 0xA5 → 0x05 |
| 取高四位，移到低位 | `(x >> 4) & 0xFu` | 0xA5 → 0x0A |
| 設第 n 位為 1 | `x |= 1u << n` | n=1，0xA5 → 0xA7 |
| 清第 n 位 | `x &= ~(1u << n)` | n=2，0xA5 → 0xA1 |
| 翻轉第 n 位 | `x ^= 1u << n` | n=0，0xA5 → 0xA4 |
| 查第 n 位 | `(x >> n) & 1u` | n=2 → 1 |

`x & mask` 只產生結果；`x &= mask` 才會寫回 x。`~x` 會翻轉整個型別的位元；只看低八位時加 `& 0xFFu`。

## 欄位替換：先清掉舊欄位，再放新值

任務：把 `x=0xA5` 的 bits 5..2 換成數值 3，其他位置不變。

```c
uint32_t mask = 0xFu << 2;     // 4 個 1 移到 bits 5..2：0x3C
x = (x & ~mask) | ((3u << 2) & mask);
// 結果 0x8D
```

只用 OR 不能清掉舊欄位裡的 1。最後再 `& mask`，避免新值超過欄位寬度改到別處。

## 完整實作題：打包、拆包、修改欄位

存成 `bits_check.c`：

```c
#include <assert.h>
#include <inttypes.h>
#include <stdint.h>
#include <stdio.h>

int main(void) {
    uint32_t x = 0xA5;
    uint32_t mask = 0xFu << 2;
    uint32_t changed = (x & ~mask) | ((3u << 2) & mask);
    assert(changed == 0x8D);
    assert((changed & ~mask) == (x & ~mask)); // 欄位外沒被改

    uint8_t bytes[4] = {0x12, 0x34, 0x56, 0x78};
    uint32_t packed = ((uint32_t)bytes[0] << 24)
                    | ((uint32_t)bytes[1] << 16)
                    | ((uint32_t)bytes[2] << 8)
                    | (uint32_t)bytes[3];
    assert(packed == UINT32_C(0x12345678));
    for (unsigned i = 0; i < 4; ++i) {
        uint8_t restored = (uint8_t)((packed >> (24u - 8u * i)) & 0xFFu);
        assert(restored == bytes[i]);
    }
    printf("changed=%02" PRIX32 " packed=%08" PRIX32 "\n", changed, packed);
}
```

```bash
cc -std=c11 -Wall -Wextra bits_check.c -o bits_check
./bits_check
```

預期 `changed=8D packed=12345678`。這裡明確指定第一個 byte 放最高位，因此打包的數值不靠主機記憶體的 endian 決定。

## 可以怎麼改來練

| 任務 | 預期 |
|---|---|
| 0xD6 高四位改成 3 | 0x36，低四位仍是 6 |
| 打包 {0xFF,0,0,1} | 0xFF000001 |
| 0x0305 拆成高低各八位再相加 | 3+5=8 |
| x=0、x=UINT32_MAX 都跑欄位替換 | 欄位外不變，欄位內等於新值 |

Python 對照 ROS 計算：

```python
a = (packed >> 8) & 0xFF
b = packed & 0xFF
answer = a + b
```

## 容易踩到的地方

- `&` 位元 AND；`&&` 邏輯 AND，結果只有真假。
- 遮罩與比較加括號：`(x & mask) == expected`。
- 用 uint32_t／無號常數做欄位操作；不要讓負數右移與有號溢位混進來。
- 32-bit 值不能移 32 位以上；`1u << 32` 不合法。
- 先轉 uint32_t 再 `<< 24`，避免 uint8_t 整數提升成 signed int 後移出範圍。
- printf 的 `%X` 是十六進位顯示；不會改數值。uint32_t 用 PRIX32 更穩妥。
