# eBNN：歷屆模型推論查閱

[← 回考場筆記入口](../README.md) · [多板分工](RP2350-eBNN從單板到多板.md)

**eBNN 是 Embedded Binarized Neural Networks，針對小型裝置減少推論所需的記憶體。** 二值化讓許多值能用 1 bit 表示，再利用位元運算處理。

它來自你提供的歷屆心得，今年未確認出題。本 repo 沒有正式模型。若題目已提供模型，主要工作可能是按規格送資料、呼叫推論、收回結果；不能因此假設所有介面都固定。

## 推論與訓練差在哪

| 名詞 | 在做什麼 |
|---|---|
| 訓練 | 用資料調整模型權重 |
| 推論 | 用已固定的權重，從輸入算預測 |
| 前處理 | 把題目資料轉成模型要求的排列、型別、數值範圍 |
| 模型暫存區 | 推論中間結果使用的記憶體 |

## 拿到模型，查這五項

| 要查的規格 | 為什麼不能猜 |
|---|---|
| 函式宣告與呼叫例子 | 模型版本可能有不同參數 |
| 輸入型別、元素數 | float 陣列、原始 bytes、打包 bits 是不同格式 |
| 前處理與位元順序 | 是否正規化、二值化、展平，依實際模型 |
| 輸出型別、長度 | 一個類別編號與一組分數不同 |
| 暫存區、狀態與標準答案 | 共用全域暫存區可能無法多核心同時呼叫 |

例：784 個 float 若每個 4 bytes，是 3136 bytes；784 個 1-bit 值可打包為 98 bytes。**只有模型／協定真的採用該格式，才能這樣傳與解讀。** 不能把任意 784 個 bytes 直接當 784 個 float。

## 二值運算：已解讀的小例子

假設每個 bit 使用相同的 +1／−1 對應：

```text
a       1010
b       1100
XNOR    1001 → 2 個位置相同、2 個不同
內積    2 × 相同數 − 位數 = 2×2−4 = 0
```

位元表示是 `~(a ^ b) & mask`；最後不足一個完整 word 時，mask 要排除填補位。popcount 是計算 1 的個數。完整模型還有層、閾值等規格，這個例子只解釋二值比較。

## 優化要對應瓶頸

| 瓶頸 | 可查方向 |
|---|---|
| 文字轉換／大量傳輸 | 兩端配套的 binary、批次處理 |
| 模型計算 | 既有位元操作、目標支援的指令、獨立樣本分工 |
| 收訊被推論卡住 | 收送與推論的 queue、雙緩衝、完成通知 |
| 多核心算錯 | 模型是否使用共享可變暫存區 |

多板通常分不同樣本，每塊有自己的模型與 RAM。分類編號要依 job_id 還原順序，不是把各板的類別相加。詳見 [多板情境](RP2350-eBNN從單板到多板.md)。
