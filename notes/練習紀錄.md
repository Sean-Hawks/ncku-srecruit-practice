# 你問過的問題：直接答案

[← 回考場筆記入口](README.md)

原本的空白能力檢核與待填練習表，改為已釐清的問題查表。

| 你的問題 | 直接答案 | 詳細位置 |
|---|---|---|
| /double 在哪裡做乘二？ | topic 名只是名稱，計算在 on_msg 的 out.data 賦值；pub 已記得目的地 | [ROS 2](技術/ROS2.md) |
| 跑 processor.py 沒反應正常嗎？ | 沒輸入時等待正常；先查 node、接線、實際輸入 | [ROS 2](技術/ROS2.md) |
| python3 processor.py 和 echo 差在哪？ | 前者執行接收／處理／發布；後者只訂閱並顯示 | [ROS 2](技術/ROS2.md) |
| 看 /number 也要 processor 嗎？ | 不用，echo 自己可以訂閱 publisher 的資料 | [ROS 2](技術/ROS2.md) |
| node list 和 topic list 差在哪？ | node 是執行功能的單位，topic 是通道 | [ROS 2](技術/ROS2.md) |
| node info 那一堆怎麼讀？ | Subscribers 看從哪接收，Publishers 看往哪送；參數服務是附帶介面 | [ROS 2](技術/ROS2.md) |
| 在外面改，Docker 會更新嗎？ | 正確 bind mount 會看到新檔案，但已跑的 Python 仍須重啟 | [Docker](技術/Docker.md) |
| 我明明在裡面開，為什麼沒變？ | shell 在哪裡不改掛載；你之前是新舊 repo 路徑接錯 | [家用環境紀錄](練習環境與路線.md) |
| 為什麼不直接 src=dst？ | 指標賦值只換指向；複製內容要迴圈／memcpy／搬運工作 | [C 指標](技術/C記憶體與指標.md) |
| main 與普通迴圈差在哪？ | main 配工作給引擎；演練引擎仍用 thread 搬，真 DMA 才是硬體 | [資料搬運](技術/資料搬運.md) |
| make 有用 engine.c、engine.h 嗎？ | .h 宣告介面；兩份 .c 編譯連結成同一個執行檔 | [編譯與 Make](技術/編譯與Make.md) |
| make mistake 正確應該怎麼填？ | count=N；N*sizeof(uint32_t) 是 bytes，錯放會多搬 | [資料搬運](技術/資料搬運.md) |
| sizeof(uint32_t) 為何是 4？ | 32 bits÷每 byte 8 bits=4 bytes | [C 指標](技術/C記憶體與指標.md) |
| push 是 queue 或記憶體嗎？ | push 是指令；FIFO 才是有限容量的硬體 queue | [PIO](技術/PIO.md) |
| RX FIFO 是什麼？ | PIO 放結果、CPU 等著讀的佇列 | [PIO](技術/PIO.md) |
| PIO 與 ROS 2 各做什麼？ | PIO 處理周邊時序／位元流；ROS 2 讓程式互傳訊息 | [底層架構](底層架構與資料流.md) |
| 簡章說的編碼／定址是什麼？ | 從指令 bits 辨識動作、算出存取位址；位址和內容分開 | [ISA](技術/ISA與指令編碼.md) |
| RP2350 就是 Raspberry Pi 電腦嗎？ | 它是微控制器；Pico 2 是搭載它的板子，與 Pi 4／5 不同 | [RP2350](技術/RP2350與PicoSDK.md) |
| 我以前 PlatformIO 開發，有什麼差？ | Build／Upload／Monitor 還是建置、寫入、觀察；底下 SDK／工具鏈依專案不同 | [ESP32](技術/ESP32.md) |
| 多塊板子怎麼放一起算？ | 分派獨立工作、附 job_id、收齊後照規格合併；不是共用同一份 RAM | [多板情境](技術/RP2350-eBNN從單板到多板.md) |
| Git 沒 tracking 怎麼拉？ | 確認正確分支與遠端，main 要追 origin/main 才設定 upstream | [Git](技術/Git與提交.md) |
| nvim Markdown 排版露出來？ | 基本語法不是完整網頁渲染；可查 conceal，完整表格直接開 GitHub | [命令表](操作清單.md#nvim-看筆記) |
