# 一頁速查：公式、資料流、提問

[← 回考場筆記入口](README.md) · [完整命令表](操作清單.md)

## 先判斷資料停在哪

```text
收到輸入 → 解析格式 → 處理／分派 → 等完成 → 包裝結果 → 回傳
```

每段只查：**型別、數量、單位、誰讀寫、完成條件**。

## ISA：看欄位與定址

以下僅為 RV32I 的 32-bit 指令；正式題目先確認 ISA。

| 欄位 | 取法 |
|---|---|
| opcode | `w & 0x7F` |
| rd | `(w>>7) & 31` |
| funct3 | `(w>>12) & 7` |
| rs1 | `(w>>15) & 31` |
| rs2 | `(w>>20) & 31` |
| funct7 | `(w>>25) & 127` |

`addi rd,rs1,8` 只加值；`lw rd,8(rs1)` 先算 byte 位址，再讀 4 bytes。I 格式立即數取 bits31..20，12-bit 的 raw 0xFFC 代表 -4。branch／store 的立即數分散，要依格式重組；x0 固定為 0。[完整格式與表](技術/ISA與指令編碼.md)

## 位元：取欄位、先清再填

```c
field = (x >> shift) & low_mask;
mask = low_mask << shift;
x = (x & ~mask) | ((value << shift) & mask);
```

用無號型別，欄位不超過型別寬度；32-bit 值不能移 32 位。bits5..2 換成 3：0xA5→0x8D。[位元表](技術/位元運算.md)

## PIO：方向以 CPU 收送理解

```text
CPU → TX FIFO → OSR → X → ISR → RX FIFO → CPU
           autopull   out   in    push       read
```

`push` 是 ISR→RX FIFO，CPU 還要讀。預設阻塞時 RX 滿會等；TX 空、需要補 OSR 時也可能等。out/in 的 32 是位數。看不到結果查啟用、輸入、push、shift／threshold。[PIO 表](技術/PIO.md)

## ROS：執行者與通道

`node list` 看誰在跑；`node info` 看接線；`topic list -t` 看通道與格式；`topic echo` 才看實際資料。

```text
publisher → /number → processor callback → /double → echo
```

`/double` 的名稱不決定公式。本 repo 現值 `3*x+1`，21→64；官方原式 `2*x`，21→42。echo 自己是接收者，不幫你執行 processor。[ROS 與無輸出查法](技術/ROS2.md)

## 共享資料：完整保護，完成後才讀

```text
mutex lock → 共享的讀／改／寫 → unlock
獨立分工 → worker 完成 → join／同步 → 合併
```

volatile 不等於 atomic／鎖。queue 若只傳指標，內容不會自動複製；buffer 要活到使用完。多板結果按 job_id 對應，不按抵達順序。[平行運算](技術/平行運算.md)

## 搬運：count 是幾筆

```text
總 bytes = count × 每筆 bytes
複製：src 前進，dst 前進
填值：src 固定，dst 前進
claim → configure → start → wait → 使用結果 → release
```

本 repo 8 個 uint32_t：count=8、每筆4 bytes、總32 bytes。錯填 count=32 就會搬128 bytes。memcpy 第三參數則是 bytes，兩套單位不同。[搬運表](技術/資料搬運.md)

## 改了沒生效

**檔案是否同一份 → 是否已重新建置 → 是否已重啟／寫入板子。** Docker mount 只接檔案；Python 通常要重啟，C 要重編，韌體要重新寫入。[Docker](技術/Docker.md) · [編譯](技術/編譯與Make.md)

## 結果對，但慢

分開量接收、解析、搬運、計算、回傳。非同步工作要等完成再停表。只有計算慢才考慮計算分工，傳輸慢先看格式與批次。[量測與除錯](技術/效能量測與除錯.md)

## 考場本地模型：一次貼一小段、只問一件事

模型沒有這份對話，也不會自動知道題目規格。依考場介面限制貼必要內容：

```text
環境／工具版本：
題目明確規定：
這段函式的輸入、輸出與長度單位：
相關程式（只貼有關函式與宣告）：
預期結果：
實際錯誤／結果：

請先依我提供的規格解釋資料流，再指出出錯的那一行。
標出缺少的資訊；不要猜 API、板型或封包格式。
若需修改，說明修改前後的結果與驗證方式。
```

特定問題可接一句：

| 情境 | 加上的問題 |
|---|---|
| ISA | 每個欄位在第幾 bit？立即數怎麼符號延伸？位址與內容分開列。 |
| PIO | 每行讀哪個暫存器、寫哪裡？在哪個條件會等待？ |
| 搬運 | count、size 與 buffer 長度各是什麼單位？總共會存取幾 bytes？ |
| 平行 | 哪個物件被誰讀寫？鎖是否涵蓋完整更新？buffer 何時可以重用？ |
| 編譯 | 只看第一個錯誤，判斷是 include、編譯、連結還是工具鏈問題。 |

模型答案用題目、函式宣告、官方手冊核對。規則與來源見 [考場規定](成大上機考規則與避雷.md)。
