# 01 改一行，看位元運算變什麼

[← 回 demo 操作回顧](../demo操作回顧.md) · [考場入口](../README.md)

> 保留原本配合 demo 的教學與操作步驟，現在可直接對照回顧。文末變化例子的答案已附，不需重新練習。

先打開 [demo_asm.c](../../demo/section2-2/demo_asm.c)，這份教學從第一個 printf 看起。

## 先認兩個符號

`0x` 表示十六進位；每一位對應四個二進位數字：

```text
A = 1010，5 = 0101，F = 1111
0xA5 = 1010 0101
```

`&` 是逐位 AND：兩邊都是 1 才留下 1。

## 原版：留下右邊四位

原本有：

```c
uint32_t x = 0xA5;
printf("x & 0x0F = 0x%02X\n", x & 0x0F);
```

先不用管 printf 格式，只看最後的 `x & 0x0F`。

```text
  1010 0101   x
& 0000 1111   0x0F
-----------
  0000 0101   0x05
```

所以原版這行印出 `x & 0x0F = 0x05`。

## 改一次：留下左邊四位

將整行 printf 換成：

```c
printf("x & 0xF0 = 0x%02X\n", x & 0xF0);
```

重編譯、執行；以下在 container 的 `/demo/section2-2`：

```bash
cc demo_asm.c -o demo_asm
./demo_asm
```

只看剛才修改的那行：

```text
  1010 0101
& 1111 0000
-----------
  1010 0000 = 0xA0
```

**改 0x0F → 0xF0，輸出 0x05 → 0xA0。** 變的是哪些位置能保留，x 本身仍是 0xA5。

## 再改一次：把留下的值移到右邊

換成：

```c
printf("high = 0x%02X\n", (x & 0xF0) >> 4);
```

```text
1010 0000 → 右移四位 → 0000 1010
```

輸出 `high = 0x0A`。這樣就取到了高四位的數值 10。`%02X` 只是以十六進位顯示，至少兩位，不足補 0。

## 補充對照：答案已附

只把 x 改成 `0x3C`，先預測下面三個結果，再執行：

```c
printf("low  = 0x%02X\n", x & 0x0F);
printf("keep = 0x%02X\n", x & 0xF0);
printf("high = 0x%02X\n", (x & 0xF0) >> 4);
```

<details>
<summary>看答案</summary>

依序是 `0x0C、0x30、0x03`。`3C = 0011 1100`，每次都畫出來逐位核對。

</details>

**這頁重點：**你能說出「AND 決定保留哪些位置，右移把它們移到哪裡」。
