## 哪些是官方線索

| 依據 | 明確寫了什麼 | 筆記如何對應 |
|---|---|---|
| [正式上機公告](https://www.csie.ncku.edu.tw/zh-hant/news/13617) 附件「考試要點」 | 閱讀文件，掌握特定系統軟硬體架構；優化程式與整體系統效能 | 架構、讀文件的方法、效能量測 |
| [官方演練 PDF](../docs/116學年度國立成功大學資訊工程學系特殊選才演練試題.pdf) 的 ROS 2 節（section2-1） | ROS 2 CLI 與訊息資料流 | ROS 2 |
| 同 PDF 的位元／PIO 節（section2-2） | 位元操作、PIO；特別提示 ISA 的基本編碼與定址、PIO 周邊章節 | 位元、ISA、PIO，為核心查閱頁 |
| 同 PDF 的臨界區／搬運節（section2-3） | 臨界區、平行概念、transfer engine | 平行運算、資料搬運 |
| 演練附的 [section2-2 說明](../demo/section2-2/README.md) | 參考 RISC-V ISA 與 RP2350 PIO 文件 | 用真實 RISC-V 編碼解釋；RP2350 查閱頁補工具脈絡 |

**演練 PDF 說明：它不是正式考題，也不包含正式考試演算法。ISA／PIO 的文字是條件式建議，不能據此確定正式板型或題型。**

ESP32、eBNN、去年多板推論只放在 [延伸技術目錄](技術/README.md#歷屆情境有出現才查)，遇到對應題目才查。Docker、Git、編譯是支援工具，與演算法題分開找。
