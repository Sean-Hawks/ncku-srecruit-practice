# 考場入口

**先看 [demo 操作回顧](demo操作回顧.md)，按例題01–05回想「做什麼、改哪裡、結果怎麼變」。** 每題都有原教學與程式連結。

要看新題目的可能變化，再讀 [猜題與解題思路](猜題與解題思路.md)。每題都有已解讀例子與作答順序。

底層名詞不熟，先查 [架構與 C 記憶體](底層架構與資料流.md)。忘了公式看 [考場速查](考場速查與離線模型提問.md)，忘了命令看 [操作清單](操作清單.md)。

GitLab 給程式後不知道怎麼放進板子，先看 [下載→建置→寫入→送測資](技術/RP2350與PicoSDK.md#從-gitlab-到板子先看這條路)。

考場模型能力有限時，直接用 [本地模型提問方法與模板](考場速查與離線模型提問.md#用26b等本地模型一次完成一個能核對的小任務)：小段規格、單一函式、最小修改、實際結果核對。
